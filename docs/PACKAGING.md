# 限定した公開範囲

ユーザーが選んだ「忠実再現のコード・説明・図・集約結果のみ」の公開版である。

含むもの: 独立移植run.py、集約用report.py、日本語文書、依存版、出典URL/SHA256、Apache-2.0 LICENSE/NOTICE、公式主実行の生成図と集約CSV/JSON。

含まないもの: NPZすべて、生データ、checkpoint、個別軌道、個別初期値、生損失列、本文条件補足のdata/図/metrics、予備実験、追加研究、環境・キャッシュ・認証情報・個人絶対パス。

拒否されたファイルの改名やformat変換は行っていない。公開集約は既存の公式主実行metricsから平均と誤差棒だけを選んだものである。既存の成功済みGit blobもこのallowlistに一致するものだけを参照する。

run.pyは公開データへの依存なしに合成生成から実行でき、必要な生配列・重みをローカルのignored runs/へ生成する。defaultはofficialだけで、本文規約補足は実行しない。既存results/は更新しない。
