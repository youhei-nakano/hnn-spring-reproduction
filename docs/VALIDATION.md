# 限定公開版の検証

公開対象は明示allowlistの20ファイル、コード・説明・公式主実行の図・集約結果だけである。NPZ、生データ、重み、個別軌道、本文規約補足、予備実験、後続研究を含めない。

- Python構文、小規模Hamiltonian微分・solve_ivp整合性を確認した。
- 公開版コード自身で合成データを再生成し、元の公式主実行データとの完全一致を確認した。非公開データを必要とする実装ではない。
- 両モデルの初期化と保存checkpointによる最終test値が一致することを確認した。検査に使ったcheckpointは公開しない。
- 公開版評価関数による著者比較セルの軌道・時刻が元結果と完全一致することを確認した。生軌道は公開しない。
- 公開版report.pyが隔離したローカルrun記録から集約JSON/CSVと公式のみの学習曲線を生成することを確認した。
- 相対リンク、公開対象allowlist、個人絶対パス・認証情報形式を検査した。

図は公式主実行の生成図であり、本文条件補足の図ではない。集約JSONは平均/誤差棒と実行条件だけに限定し、個別初期値・個別損失列を削除した。拒否済みの数値ファイルを別名・別formatで送信するものではない。

validation.jsonに検査結果を保存した。パターン検査だけで秘密不存在を形式的に証明するものではなく、内容を選別したallowlistと併用している。
